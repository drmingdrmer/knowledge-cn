## 颜色区分卡片种类，连线区分关系

每张卡片解释一个知识点。无色卡片是概念，青色是定理，黄色是解释，绿色是例子，红色是警示。

灰色箭头从前提卡片的右侧连接到结论卡片的左侧。沿着灰色箭头从左向右阅读，就能逐步理解后面的结论。

绿色箭头从卡片底部向下连接例子、解释或其他补充内容。紫色连线在卡片顶部连接相关主题。分组框的颜色只用于区分区域。

## 拖动背景和缩放来浏览地图

拖动背景可以平移地图。点击 **Fit**，可以让整张地图进入视野。
用触控板双指缩放，或者按住 Ctrl 或 Command 并滚动鼠标滚轮来缩放。

通过 **Search cards** 搜索卡片。**Wide** 可以加宽卡片，**Actual** 恢复地图中保存的尺寸。

## 点击卡片阅读内容

选中卡片后按空格展开，再按一次收起。

点击卡片后，滚轮会滚动卡片内部的内容。点击背景后，滚轮恢复操作地图。

点击卡片标题可以打开阅读视图。标题旁的源码按钮显示 Markdown 源文。
卡片中的知识链接指向相关卡片。

## 复制地址分享当前视图

浏览地图时，地址会记录当前位置。复制地址即可分享当前视图或选中的卡片。
