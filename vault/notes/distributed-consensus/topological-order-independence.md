# 拓扑序无关性：完备依赖保证所有合法顺序得到相同终态

从相同初态出发，对同一个依赖完备的有限命令 DAG，使用相同的确定性状态转移执行每个节点恰好一次，任意拓扑序都会得到相同的最终状态。

## 证明：每次交换不可比节点都保持终态

拓扑序无关性（Topological-order Independence）在这个有限执行模型中，也可以称为执行合流性（Execution Confluence）。各条执行路径最终汇合到同一状态。

证明使用四个前提：

- [[deterministic-state-machine|确定性状态机]]保证相同状态执行相同命令序列，产生相同状态与输出。
- [[command-commutativity|状态可交换性]]保证从模型允许的每个状态出发，交换一对可交换命令保持执行后的状态。两种顺序都须有定义。
- [[conflict-coverage|依赖完备性]]保证每对不可比命令都可交换。
- [[adjacent-swap-lemma|相邻交换引理]]保证任意两种拓扑序可以通过交换相邻不可比节点互达。

取任意两种拓扑序，按相邻交换引理逐步转换。对于其中一步：

1. 交换位置之前的命令序列相同，因此两个执行到达相同状态。
2. 被交换的两个节点不可比。依赖完备性与可交换性保证，交换后这两步到达相同状态。
3. 交换位置之后的命令序列相同。确定性保证剩余执行仍到达相同终态。

每次交换都保持终态，所以转换前后的两种拓扑序具有相同终态。

## 例子：交换两个独立键的写入得到相同状态

若命令 `A` 设置 `x = 1`，命令 `B` 设置独立键 `y = 2`，两条命令可交换。DAG 可以保留两个互不可比的节点。从空映射开始，拓扑序 `A, B` 与 `B, A` 都得到 `{x: 1, y: 2}`。

## 补充：返回值一致需要语义可交换性

若依赖完备性采用保持返回值的语义可交换性，同一证明还保证每个命令实例的返回值相同。仅要求状态可交换性时，结论只覆盖最终状态。

## 补充：依赖完备性是充分条件

依赖完备性给出了拓扑序无关性的充分条件。若只比较整个 DAG 执行后的状态，它并非必要条件：例如，最后一条命令将整个状态重置为固定值，也可能消除此前的顺序差异。
