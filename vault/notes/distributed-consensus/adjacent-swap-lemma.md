# 相邻交换引理：任意两种拓扑序可通过交换不可比节点互达

相邻交换引理（Adjacent Swap Lemma）指出，同一个有限 DAG 的任意两种拓扑序，都可以通过有限次相邻交换互相转换。每次交换的两个节点在 DAG 的可达关系下不可比，因此交换后仍是合法拓扑序。

## 证明：逐个对齐目标拓扑序的首节点

[[topological-order-and-linear-extension|拓扑序]]也称为偏序的线性扩张。引理只涉及节点的先后约束；交换命令是否保持状态，由命令的可交换性另行保证。

证明可以按节点数归纳：

1. 取目标拓扑序的第一个节点，称为 `first`。
2. 在当前拓扑序中，所有排在 `first` 前面的节点都与它不可比。若某节点必须先于 `first`，目标序就不合法；若 `first` 必须先于某节点，当前序就不合法。
3. 将 `first` 逐步向左移动，每次只交换它与左侧相邻节点。两个节点不可比，交换会保留全部先后约束。
4. 首节点对齐后，固定首节点，对剩余节点重复归纳。空序列与单节点序列已经相同。

## 例子：两次相邻交换保留 A 先于 C 的约束

例如，只有依赖 `A → C` 时，`A, C, B` 可以先交换 `C, B` 得到 `A, B, C`，再交换 `A, B` 得到 `B, A, C`。每一步都只交换不可比节点。
