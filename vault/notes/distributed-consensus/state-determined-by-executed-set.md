# 相同已执行集合的状态唯一性：合法调度得到相同状态

两个副本从相同初态出发，在同一个依赖完备的命令 DAG 上使用相同的确定性状态转移。若两个副本的已执行集合相同，集合有限且依赖闭合，每个节点都各自恰好执行一次，它们就处于相同状态，即使本地执行顺序不同。

## 证明：共同执行集合的诱导子图具有唯一终态

“同一个命令 DAG”要求两个副本对命令实例的标识、命令内容及依赖关系有一致解释。本地执行须遵守依赖顺序。

证明使用[[dependency-closed-execution|依赖闭合集]]与[[topological-order-independence|拓扑序无关性]]：

1. 将共同的已执行集合及其内部边取出，得到有限诱导子图。依赖闭合保证每个已执行节点的全部祖先都包含在子图中。
2. 依赖完备性仍然成立。如果两个保留节点间原有排序路径，这条路径上的节点都是后一个节点的祖先，因此也保留在子图中。
3. 两个副本的本地执行顺序，都是子图的拓扑序。
4. 根据拓扑序无关性，从相同初态执行这个子图的任意拓扑序，都会得到相同状态。

因此，初态、命令 DAG 和执行规则固定后，状态可以表示为依赖闭合集的函数。

## 例子：两个副本以相反顺序写入独立键

例如，两条独立命令分别设置键 `x = 1` 和 `y = 2`。两个副本按相反顺序执行后，都到达 `{x: 1, y: 2}`。只完成其中一条命令的副本可以处于另一状态。

## 补充：返回值一致要求语义可交换性

若依赖完备性采用保持逐命令返回值的语义，两个副本按命令标识记录的返回值也相同。

## 补充：增长日志须先确定命令与依赖

对于持续增长的日志，协议还需保证命令与依赖在应用前已经确定，并保持已执行节点的祖先集合稳定。协议必须另行证明副本能够就这些信息达成一致；本卡片证明的是既定 DAG 上相同执行集合的状态一致性。
