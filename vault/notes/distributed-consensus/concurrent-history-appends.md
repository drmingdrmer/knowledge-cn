# 并发追加：唯一新标识保持历史兼容

从共享根且共同记录一致的历史树出发，不同写入者各自使用全局唯一的新标识追加，所得历史仍然兼容，可以取并集合并并保留双方的全部节点。

## 证明：共同记录保持不变，新记录彼此区分

1. 根据[[history-tree-extension|历史树追加]]，每个写入者追加后仍持有合法历史树，原有节点的记录保持原样。
2. 根据[[immutable-history-trees|不可变历史树]]，不同写入者独立创建的新节点标识全局不同；复制同一节点时保留原记录。因此合并双方对任何共同标识仍给出相同记录。
3. 两棵历史树共享根、共同记录一致且包含全部祖先，满足[[monotone-union|单调合并]]的条件。取并集得到合法历史树，并保留双方的全部节点。

## 例子：同一父节点下的两次并发追加

两个写入者都持有 `root → A`，分别追加新节点 `B` 和 `C`。合并后，`A` 同时具有子节点 `B` 与 `C`，两条历史 `root → A → B` 和 `root → A → C` 都得到保留。
