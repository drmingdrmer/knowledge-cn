# Read Quorum：完成一次读取所需的副本集合

Read Quorum 是协议允许完成一次读取的副本集合。在本历史模型中，读取者收齐其中每个成员的当前完整历史，才完成这次 Quorum 读取。

## 定义：从允许的读集合中收齐当前历史

协议先规定允许的读 [[quorum|Quorum]] 集合族。一次读取选定其中一个集合，向每个成员发送本次读请求，并收集每个成员处理请求时的当前完整历史。

读取者收齐该集合的全部回复，再按[[monotone-union|单调合并]]取历史并集。已完成写入为何出现在这个并集中，由[[quorum-visibility|Quorum 可见性]]结合相交与持久化条件证明。

## 例子：读二配置需要两个成员的当前回复

五个副本允许任意两个组成 Read Quorum。选中 `{A, D}` 后，读取者收集 `A` 与 `D` 对本次请求的回复，再将两份历史合并。
