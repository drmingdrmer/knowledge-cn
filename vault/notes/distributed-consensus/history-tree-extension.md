# 历史树追加：添加新子节点后仍是树

在不可变历史树中，以已有节点为父节点，用全局未使用的标识创建一个新子节点，结果仍是合法历史树，并保留原树的全部节点与父边。

## 证明：新节点接入已有根路径，原有记录保持原样

依据[[immutable-history-trees|不可变历史树]]的模型，新节点标识全局唯一，创建后绑定固定的父节点与命令。

1. 新标识尚未出现在任何已有记录中，追加时原有节点与父边保持原样。
2. 父节点已在树中，因此它具有唯一且完整的根路径。沿这条路径再走到新子节点，就得到新节点的唯一根路径。
3. 新节点位于已有路径末端，追加后的每个节点仍有唯一父路径并最终到达共同根。因此结果仍是一棵包含原树的历史树。

## 例子：在已有节点 A 下追加 B

原树为 `root → A`。创建全局唯一的新节点 `B`，固定其父节点为 `A`，结果为 `root → A → B`，其中 `root` 与 `A` 的记录保持原样。
