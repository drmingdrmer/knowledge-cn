# 依赖闭合集：每个已执行节点的全部前驱都已执行

若系统只在节点的全部直接前驱已经执行后才执行该节点，那么任何时刻的已执行集合都包含其中每个节点的全部祖先。

## 证明：加入已就绪节点保持依赖闭合

这样的集合称为偏序的向下闭合集（Down-set），也称序理想（Order Ideal）。在命令 DAG 中，可以称为依赖闭合集。祖先由[[topological-order-and-linear-extension|DAG 的可达关系]]定义，包括通过多条边到达当前节点的所有前驱。

证明可以沿执行步骤归纳：

1. 初始已执行集合为空，满足依赖闭合。
2. 假设当前集合依赖闭合。新节点可以执行时，它的全部直接前驱都已在集合中。
3. 每个直接前驱的全部祖先也已在集合中，因此新节点的全部祖先都已执行。加入新节点后，集合仍依赖闭合。

所以，拓扑序的每个前缀都形成依赖闭合集。反过来，有限 DAG 的任意依赖闭合集都能作为某种拓扑序的前缀：先拓扑排序集合内部，再拓扑排序剩余节点。闭合性保证剩余节点中没有节点必须排在集合内的节点之前。

## 例子：副本可以停在不同的依赖闭合集

例如，`A → C`、`B → C` 的依赖闭合集包括 `{}`、`{A}`、`{B}`、`{A, B}` 和 `{A, B, C}`。两个副本可以分别执行到 `{A}` 和 `{B}`，即使各自合法执行，它们的线性执行列表也未必互为前缀。
