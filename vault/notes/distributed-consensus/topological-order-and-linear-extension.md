# 拓扑序：DAG 所定义偏序的线性扩张

有限有向无环图（DAG）至少存在一种拓扑序。拓扑序包含每个节点恰好一次，并让每条有向路径的起点排在终点之前。

## 证明：DAG 的可达关系可扩张为全序

在命令 DAG 中，每个节点表示一个有唯一标识的命令实例。边 `先执行 → 后执行` 表示执行约束。即使命令内容相同，两次调用也分别对应两个节点。

只要存在从命令 `before` 到命令 `after` 的有向路径，就记作 `before ≺ after`。可达关系具有传递性；无环性保证节点不会先于自身。因此，可达关系定义一个严格偏序。补上节点与自身相等的关系，就得到通常的偏序。

拓扑排序（Topological Sort）产生的拓扑序（Topological Order），就是这个偏序的线性扩张（Linear Extension）：它把全部节点排成一个全序，同时保留偏序中已有的先后关系。

拓扑序的存在性可以按节点数归纳证明：

1. 非空有限 DAG 必有一个入度为零的节点。否则，沿入边不断寻找前驱，有限个节点中必有节点重复，从而形成有向环。
2. 将这个节点放在首位，删除节点及其出边。剩余图仍是有限 DAG。
3. 对剩余图重复上述步骤，直到全部节点排完。空图对应空序列。

## 例子：两个独立前驱可以按不同顺序执行

例如，`A → C`、`B → C` 允许 `A, B, C` 和 `B, A, C` 两种拓扑序。`A` 与 `B` 互不可达，因此它们在偏序中不可比。
