# 确定性状态机：相同初态与命令序列产生相同结果

两个副本运行相同的确定性状态机，从相同的初始状态出发，按相同顺序执行相同命令，就会得到相同的状态与输出序列。

## 证明：相同状态执行相同命令仍得到相同状态

确定性状态机（Deterministic State Machine）根据当前状态和命令，唯一确定下一状态和本次输出。

证明可以按已执行的命令数量归纳：

1. 执行任何命令之前，两个副本的状态相同，输出序列都为空。
2. 假设执行前若干条命令后，两个副本的状态相同，输出序列也相同。
3. 两个副本接着执行相同的下一条命令。由于当前状态相同、转移规则相同且确定，本次输出与下一状态也相同。追加后的输出序列仍然相同。

由数学归纳法，结论对任意长度的有限命令序列成立。

## 例子：两个计数器都经历 0 → 2 → 6

例如，两个副本的计数器都从 `0` 开始，依次执行“加 2”“乘 3”，并在每步返回更新后的计数值。两个副本都会经历 `0 → 2 → 6`，输出序列都是 `[2, 6]`。

## 补充：时间与随机数的具体值应写入命令

若命令依赖当前时间或随机数，应先将具体值写入命令，让各副本重放时使用相同的值。
