# 历史的单调合并：取并集保留已有节点与并发分支

两棵共享根节点、共同节点记录相同且各自包含全部祖先的不可变历史树，可以通过节点记录的并集合并。合并结果仍是合法历史树，并包含两棵输入树的全部历史。

## 证明：共同记录兼容，原有根路径完整保留

历史的单调合并（Monotone Union）以集合包含关系衡量增长：合并后的记录集合包含每一份输入记录集合。

根据[[immutable-history-trees|不可变历史树]]模型，每条记录包含节点标识、父节点标识与命令。兼容的历史对共同标识给出完全相同的记录。

1. 取记录并集时，共同标识对应的记录相同，因此每个节点仍然只有一个父节点与一份命令。
2. 并集中的任意节点来自至少一棵输入树。该输入树已经包含节点到共同根的完整路径，并集保留这条路径。
3. 每个节点都有唯一父路径并最终到达共同根，所以合并结果仍是树，且保留两份输入的全部节点。

## 例子：合并两条分支后同时保留 B 与 C

一棵树包含 `root → A → B`，另一棵包含 `root → A → C`。两份 `A` 的记录相同，`B` 与 `C` 的标识不同。取并集后，`A` 同时拥有子节点 `B` 和 `C`，两条候选历史都被保留。

## 补充：合并顺序与重复合并不影响记录并集

集合并集满足交换律、结合律和幂等律。因此，对同一批兼容记录，改变合并顺序、分批合并或重复接收记录，都会得到相同的记录集合。这里的性质作用于历史记录合并；业务命令的执行结果还取决于命令语义与执行规则。
