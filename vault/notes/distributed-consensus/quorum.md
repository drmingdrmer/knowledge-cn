# Quorum：协议规定的足够参与者集合

Quorum 是协议规定的、足以完成某个步骤的参与者集合。协议可以允许多种成员组合，这些允许的集合共同构成该步骤的 Quorum 集合族。

## 定义：协议决定哪些成员组合足够

本模型给定一个固定、有限且非空的副本集合。协议为每个步骤规定一族允许的副本子集，执行该步骤时从中选择一个集合，这个选中的集合就是一次执行使用的 Quorum。

“一个 Quorum”指具体的成员集合；“Quorum 集合族”指该步骤允许选择的全部集合。[[read-quorum|Read Quorum]] 与 [[write-quorum|Write Quorum]] 分别用于读取与写入，两类集合之间的关系由[[quorum-intersection|Quorum 相交约束]]规定。

## 例子：同一步骤可以允许多种成员组合

成员为 `{A, B, C, D, E}`。若某个步骤允许任意两个副本参与，则 `{A, C}` 与 `{B, D}` 都是这个步骤可选的 Quorum。
